Pipeline

保守，是刻意的选择#

从文件系统事件到归档落位，每一步都有明确的「不做什么」：无法证明完成的文件不动，证明不了安全的目录不碰。

01

事件唤醒与扫描

顶层整理由 Dispatch 事件唤醒；整个「下载」目录的只读索引由递归文件事件触发重新扫描。事件负责提醒，实际目录状态才是判断依据。

event → scan
02

完成判定

隐藏与临时文件直接跳过；候选文件的大小须在两次检查间保持不变，且未被协作进程独占加锁。无法证明完成，就延迟重试。

size ×2 · lock
03

日期路由

实时下载记完成当天；手动整理的旧文件取创建日期（回退修改日期），映射到唯一的归档路径。

Day / Month / Year
04

安全移动

全程持有咨询锁，校验卷与 inode 身份。重名追加序号、绝不覆盖；任何一步失败，源文件原样留在原地。

name (n).ext
05

记录与刷新

整理记录永久保存在本地 SQLite；文件索引同步记录发现、重命名、移动与修改，查询界面随扫描结果刷新。

local index · SQLite
Features

菜单栏里的一件小工具#

一眼看整理状态，一键进入今日文件夹；需要找旧文件时，再打开覆盖整个「下载」目录的文件查询。

今日下载，一点即达

「今日下载」模块既是状态面板，也是访达入口——点标题、空白态或文件列表，都会创建（如需要）并打开今天的归档文件夹。创建即写入完整日期标记，纳入受管记录。

~/Downloads/Day 2026-08-12/

暂停与继续

随时一键暂停自动移动；只读索引不会停，文件查询仍会继续跟上目录变化。

立即整理现有文件

首次授权后由你明确选择：把已堆积的顶层文件按创建日期一次性归位。应用启动时不会自作主张。

全下载目录文件查询

递归索引任意深度的文件：无论是 DayDrop 归档的，还是你直接存进二级、三级目录的，都能按名称、路径和类型查找；当前文件与已不可用记录统一呈现。

变化识别，保持克制

发现、重命名、目录内移动和修改会更新索引；复制件按新文件记录。文件消失时统一标记为「移出或删除」，不会在无法证明时猜测它究竟被删除还是移到了下载目录之外。

永久整理记录

成功与失败操作永久保存在本地，可搜索、按文件类型筛选、导出 CSV / JSON，并在访达中定位。

登录时自动启动

macOS 13 登录项 API，面板与设置页里的开关绑定同一运行时状态。

整理完成通知

默认关闭。开启后每批整理完成发一条系统通知，授权与否都如实反馈。

绝不覆盖

目标重名时自动追加 (n) 序号；移动失败时源文件原样保留。

Connected Apps

让整理后的文件继续流动#

DayDrop 只在本机发现兼容版本后显示连接入口。文件仍由你从具体条目发起，不会在后台自动传给其他应用；兼容调用方还可以请求把今日文件夹窗口放到发起操作的显示器。

F

搁这儿-ForNow

一个放在 Mac 屏幕刘海旁的临时暂存区。安装兼容版本后，可以在 DayDrop 的「今日下载」「下载文件」和「整理记录」中右键选择「添加到搁这儿-ForNow」，把仍然存在的当前文件交给它暂存。

Privacy & Security

你的文件，不出这台 Mac。

文件整理、递归索引和查询始终在本机完成；只有检查软件更新时，才会访问 DayDrop 官方网站，且不会上传文件名、文件内容或操作记录。

文件处理完全本地

整理逻辑、文件索引、元数据与操作记录全部留在本机。网络权限只用于从官网获取签名更新清单与安装包。
local file processing

App Sandbox 最小授权

仅持有你亲手选择的「下载」文件夹读写权限，并通过安全作用域书签持久化，重启后依然有效。

不读文件内容

整理判断与递归索引只使用路径、名称、时间、大小、文件类型等元数据，以及文件是否被独占打开；内容本身，从不读取。

公证过的发行版

DMG 以 Developer ID 签名并通过 Apple 公证，票据已装订，Gatekeeper 直接放行。
